# gaia-site

The landing page for **Gaia**, a deep time planet simulator - served at
GitHub Pages, and the home of the Windows download.

**Downloads:** see [Releases](https://github.com/SteveCastle/gaia-site/releases/latest).

This repo holds only the published page and the release binaries. It is
generated: the page is authored in the (private) game repo under `site\` and
mirrored here by `build\publish-site.ps1`. Edits made directly here are
overwritten on the next publish.
